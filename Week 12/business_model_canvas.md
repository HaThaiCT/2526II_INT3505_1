# Business Model Canvas - Demo API

- **Value Propositions:**
  - Easy-to-use demo API for teaching API product thinking.
  - Fast onboarding via developer portal + sandbox.
  - Clear pricing: free tier + pay-per-call for higher usage.

- **Customer Segments:**
  - Students learning API architecture.
  - Internal teams prototyping integrations.

- **Channels:**
  - Developer portal (this demo), docs, classroom slides.

- **Customer Relationships:**
  - Self-service docs + sandbox, email support for paying customers.

- **Revenue Streams:**
  - Freemium: free up to 100 calls/month.
  - Pay-per-call for additional usage ($0.01/call simulated).
  - Potential subscription for bundled calls.

- **Key Resources:**
  - API infrastructure, billing connector, analytics.

- **Key Activities:**
  - Developer onboarding, monitoring, billing.

- **Key Partners:**
  - Payment provider, analytics provider.

- **Cost Structure:**
  - Hosting, monitoring, developer portal maintenance.

KPIs to monitor: developer signups, monthly call volume, error rate, revenue per developer.
